# Rajputana — Relishing Traditional Flavours

A premium responsive restaurant website concept for Rajputana, Hoodi/Whitefield, Bengaluru.

## Included

- Rajasthani restaurant themed design
- Hero section
- Traditional dishes and prices
- Restaurant story
- Food gallery
- Reviews section
- Table reservation form
- WhatsApp reservation integration
- Call button
- Google Maps directions
- Mobile navigation
- GitHub Pages ready
- Real food/restaurant demo images loaded from Unsplash image CDN

## WhatsApp booking

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`.
3. Open Settings → Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/ (root)`.
6. Save.

## Important

The food photographs are demo images hosted through the Unsplash image CDN. For a commercial client website, replace them with the restaurant's own approved photos or properly licensed images.
